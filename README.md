# Виджет банковских операций

Проект содержит утилиты для обработки и фильтрации банковских транзакций.

## Модули
- `src/masks.py` — маскировка номеров карт и счетов.
- `src/widget.py` — форматирование дат и входных данных.
- `src/processing.py` — фильтрация по статусу и сортировка по дате.
- `src/generators.py` — генераторы карт и обработка транзакций.

## Запуск и тесты
1. Установка зависимостей: `poetry install`
2. Запуск тестов: `pytest`
3. Проверка покрытия: `pytest --cov=src`
