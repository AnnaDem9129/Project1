# Виджет банковских операций

Проект представляет собой набор утилит для фильтрации и сортировки транзакций личного кабинета клиента.


## Инструкция по установке и использованию

1. Клонируйте репозиторий на свой ПК.
2. Установите зависимости проекта с помощью `poetry install`.
3. Импортируйте нужные функции в свой код:

```python
from src.processing import filter_by_state, sort_by_date

# Пример фильтрации
executed_ops = filter_by_state(data, 'EXECUTED')

# Пример сортировки
sorted_ops = sort_by_date(data)
